# Qwertycoin v2.0.0-rc.1

This release candidate targets the public Qwertycoin v2 mainnet launch with
public mining. It is not final until every launch gate below has been completed
and recorded.

## Target

```text
network: mainnet
release: v2.0.0-rc.1
image: qwertycoin-v2-node:v2.0.0-rc.1
p2p: 8196
daemon rpc: 8197, local/private
restricted rpc: 8198, optional and protected
zmq rpc: 8199, local/private
pow: RandomX
epose: enabled from genesis
```

## Included

- QWC v2 mainnet parameters.
- RandomX proof of work.
- EPoSE registration, attestation, qualification, and service rewards.
- Denominated EPoSE reward outputs for spendability.
- QWC-branded daemon, wallet, wallet RPC, and blockchain utility binaries.
- Mainnet seed deployment manifests under `deploy/mainnet`.
- Observer-only Explorer support through the separate Explorer repository.

## Explicitly Excluded

- The closed QWCP public-address prototype branch / PR #14.
- Transparent public reward-output mode.
- Inherited Monero update metadata or DNS checkpoint records.

## Required Launch Gates

- Current `main` or release branch builds reproducibly for the release target.
- `deploy/mainnet/build-rc-image.sh` produces
  `qwertycoin-v2-node:v2.0.0-rc.1` from a clean worktree.
- EPoSE unit tests pass.
- EPoSE fuzz seed corpus passes.
- EPoSE AddressSanitizer unit and fuzz runs pass.
- Public seed nodes start from `qwertycoin-v2-node:v2.0.0-rc.1`.
- `seed-00`, `seed-01`, and `seed-02` all report the same genesis hash.
- A fresh independent node bootstraps through DNS seed discovery without manual
  priority nodes.
- Public mining produces blocks from a non-seed miner.
- Service-node registration is mined on-chain.
- Attestations relay between public peers.
- EPoSE service reward is mined after qualification.
- A matured denominated EPoSE reward is spent by the operator wallet and
  received by a recipient wallet.
- Explorer reports mainnet, current height, mempool, EPoSE status, and recent
  blocks from the public seed network.
- Release artifact hashes are generated and published before user-facing
  download links are announced.

## No-Go Conditions

- Any seed hostname resolves to a node with a different network id.
- Fresh DNS-only bootstrap fails from an independent network.
- Public RPC or ZMQ is exposed without an explicit protection layer.
- Any launch node runs an older PR/testphase image tag.
- Reward spend validation remains incomplete.
- CI or local replacement validation is red.

## Operator Notes

Use `deploy/mainnet/seed-00.env`, `seed-01.env`, and `seed-02.env` only after
building and distributing the `qwertycoin-v2-node:v2.0.0-rc.1` image. Preserve
service identity volumes during ordinary chain resets so service-node identity
does not accidentally rotate.
