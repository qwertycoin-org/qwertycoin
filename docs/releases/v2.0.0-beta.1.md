# Qwertycoin v2.0.0-beta.1

This release note describes the Qwertycoin v2 EPoSE testnet beta target. It is
not a mainnet release.

## Included

- Monero-based QWC v2 chain with current consensus rules inherited at genesis.
- RandomX proof of work.
- QWC HF17 active from genesis.
- EPoSE service-node registration and qualification.
- Consensus-visible service rewards.
- EPoSE daemon RPC and daemon console status commands.
- Wallet CLI `register_service_node` command for non-mining operators.
- Docker image and Docker Compose based testnet startup.
- Pruning remains available for normal nodes where supported; service-node mode
  requires an unpruned chain.

## Experimental

- EPoSE parameters are beta parameters and may change.
- Admission proof is deliberately cheap and intended for testnet only.
- Reward split and reward selection are beta parameters.
- Service scoring and verifier assignment may change before mainnet.
- Chain resets remain possible during the testnet beta.

## Not Mainnet Ready

- Admission/Sybil security is not mainnet-ready.
- No external security review has been completed.
- Longer fuzz and chaos campaigns are still required.
- Larger 25+ node validation is still required on suitable hardware.
- Final token migration, distribution, and mainnet genesis decisions are open.

## Beta Rules

```text
network: testnet
coin value: none
hardfork: HF_VERSION_QWC_EPOSE_V1 = 17 from height 0
old chain data: incompatible, delete before joining
consensus: may change during beta
```

## Ports

```text
P2P:        8196
daemon RPC: 8197
wallet RPC: 8198
ZMQ RPC:    8199
```

Daemon RPC and ZMQ RPC should stay bound to localhost unless an operator
intentionally exposes a restricted public endpoint.
